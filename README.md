# Life: Your Story — Neighbourhoods 0.7

A browser-based life simulation prototype.

## Play

Open the game here (once GitHub Pages is enabled):

**https://ewawere.github.io/life-your-story/**

Or just open `index.html` locally in any modern browser.

## Features

- Create your character (name, skin, hair, shirt colour)
- Procedural family (background, income, guardians, siblings)
- 3D neighbourhood with three areas (Maple Close, Hillcrest Gardens, Riverside Terrace)
- School lessons + timed exams (Maths, English, Science)
- University applications with entrance exams & scholarships
- Neighbour relationships & house visits
- Needs system (hunger, fun, social, hygiene, energy, mood)
- Day/night cycle, rain, bus travel, shopping, cooking, exercise, home decoration
- Local save (browser localStorage)

## Controls

- **Joystick** (bottom left) or WASD / arrow keys to move
- **Right half of screen** to look around
- **Yellow action button** when near something interactable
- Menu button (top right) for progress, family, save, etc.

Made as a single-file prototype using Three.js.
